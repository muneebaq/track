What it does

A small Python tool that turns a printed square of paper into an anchor for any 3D model you already have.

.glb / .gltf / .obj

Any model you already have

Point --model at a file and go — no format conversion needed for glTF, GLB, or OBJ+MTL.

solvePnP

Precise pose tracking

OpenCV's ArUco detector plus solvePnP anchor the render to the marker's exact position and angle, frame by frame.

--rotate-speed

Built-in motion

Idle rotation, a gentle float, and a pulsing marker ring — all tunable from the command line.

How it works

Every frame runs the same four-step pipeline, entirely on your machine.

01

Detect

The webcam frame is scanned for the printed marker.

02

Solve

solvePnP recovers the marker's position and orientation.

03

Render

The 3D model is drawn from that exact camera viewpoint.

04

Composite

The render is blended back into the live video frame.

Install

Python 3.10 or 3.11 is recommended — pyrender's OpenGL bindings are unreliable on newer interpreters.

pip install opencv-contrib-python pyrender trimesh "numpy<2" requests PyOpenGL

Run it

Print a marker once, then track any model against it.

# 1. Generate and print a tracking marker
python marker_ar_viewer.py --make-marker marker.png
# 2. Track your own model
python marker_ar_viewer.py --model bee.glb --model-scale 0.02
# Windows webcam giving MSMF errors?
python marker_ar_viewer.py --model bee.glb --backend dshow

Model formats

.glb / .gltf
Loads directly, no conversion needed.
.obj + .mtl
Loads directly — keep both files in the same folder.
.fbx
Convert once with the included Blender script, then load the resulting .glb like any other model.

If nothing renders

  • Check the console for the printed bounding-box size and suggested --model-scale at startup.
  • Confirm the on-screen text reads a detected marker ID, not "No markers detected".
  • Make sure the marker's real-world size matches --marker-size, in meters.
